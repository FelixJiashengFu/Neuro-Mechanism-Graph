## 分层标注

- **实线（青）**：酶解、LRP1/RAGE 转运、吞噬与溶酶体降解等已被广泛验证的部分。
- **虚线（琥珀）**：类淋巴通路的驱动力、睡眠的因果作用、APOE4 对外排效率的影响。
- **点虚线（洋红）**：RAGE 内流、CAA 堵塞血管周通路等会抵消清除的分支。
