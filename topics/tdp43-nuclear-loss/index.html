Topic 04 · TDP-43：核丢失与胞质聚集

TDP-43 的病理有两张面孔，别只画其中一张

几乎所有肌萎缩侧索硬化、约一半额颞叶变性，以及相当比例的老年脑，都带有 TDP-43 病理。它的特征不是"多了一团聚集物"，而是同时发生的两件事：细胞核里本该在的 TDP-43 不见了，细胞质里出现了磷酸化、泛素化的聚集物。本页把这两面分开画，再说明近年最硬的那条证据链——隐蔽外显子。

  • 已验证的通用生物学 established
  • 有支持但仍待检验 to be tested
  • 病理分支 pathological branch
一句话定位：TDP-43 是核内 RNA 结合蛋白，日常工作是剪接调控、转录调控与 RNA 稳定性维持。3所以"它从核里消失"本身就是一次功能事故，不必等到聚集物显形。
机制 1 / AUTOREGULATION

自调控：一个会被自己打断的闭环 已验证

TDP-43 蛋白会结合自身 mRNA 的 3′ 非翻译区，促使其被降解或发生非生产性剪接，从而把自己的量压回去。4这是一个标准的负反馈negative feedback。

机制 2 / CRYPTIC EXONS

隐蔽外显子：近年最硬的一条因果链 多组独立重复

基因组里有许多隐蔽外显子cryptic exon——平时被压着、不参与成熟 mRNA 的序列。TDP-43 的工作之一就是压住它们。6TDP-43 一旦离开核，这些序列被错误纳入，使转录本提前终止或被降解。

为什么这条链说服力强

它同时满足三项：有可测的中间产物、有独立实验室重复、并与人类遗传学结果吻合。神经退行领域能同时满足这三项的机制并不多。

隐蔽外显子出现 ≠ 它造成了死亡

它是 TDP-43 失能的忠实读数；要证明它本身致病，还得单独补回 STMN2 / UNC13A 看表型是否挽回。

机制 3 / PHASE SEPARATION

相分离与应激颗粒：路径之一，未必是必经之路 有争议

TDP-43 的 C 端低复杂度结构域low-complexity domain, LCD可驱动液—液相分离liquid–liquid phase separation，形成无膜的浓缩相；这类液滴在持续应激下可发生液固转变liquid-to-solid transition并走向纤维化。11一个流行的叙述是：应激颗粒 → 成熟 → 变成病理包涵体。

支持面

LCD 突变会改变相行为，并与家族性病例的突变位置重叠；体外可重现从液滴到纤维的过程。

反例

也有研究观察到不依赖应激颗粒的胞质 TDP-43 去混合过程，并伴随核输入受损——说明应激颗粒可能是旁路而非必经站。13

在体外会相分离 ≠ 在细胞里走这条路

体外体系的蛋白浓度与拥挤剂通常远离生理条件。把体外相图直接当成细胞内机制，是这一小节最常见的跳步。

还有一层：核质转运本身。有工作报告 TDP-43 病理与核孔复合体nuclear pore complex及转运因子的异常相互强化。14若成立，"核丢失"与"胞质聚集"就不是两条平行线，而是一个闭合的恶性循环——这也是图 1 里那句"可能互为因果"的出处。

验证 / EVIDENCE

想说"TDP-43 失能"，拿什么读数

要回答的问题合适的读数常见误用
核里真的少了吗？核／胞质分别定量，而不是只看总量；单细胞水平比群体平均更有意义WB 总蛋白量不变就断定"没变化"
功能真的丢了吗？隐蔽外显子纳入的 RT-PCR / 测序读数——这是功能的直接指标只做聚集物染色，不测下游剪接
聚集物有没有毒？把聚集与功能丧失解耦：如保留核功能而强制胞质聚集把包涵体数量当作疾病严重度的代名词
干预有效吗？补回下游靶点（如 STMN2）看表型是否部分挽回只看 TDP-43 总量下降就宣称有效

结论 / BOTTOM LINE

核心结论

① 两面并存

核丢失与胞质聚集都要画；只画包涵体会漏掉最可干预的一半。

② 隐蔽外显子是最好的功能读数

可测、可重复、与人类遗传学吻合。

③ 相分离：机制候选，非定论

应激颗粒未必是必经中间体；体外相图不能直接当细胞内路径。

④ 自调控是实验设计的坑

过表达会触发负反馈，敲低与过表达必须各设对照。
