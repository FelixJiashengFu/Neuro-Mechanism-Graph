## 分层标注

- **实线（青）**：核内 RNA 结合功能、自调控、隐蔽外显子去抑制（多组独立重复，并与人类遗传学吻合）。
- **虚线（琥珀）**：相分离与应激颗粒作为必经中间体的假设。
- **点虚线（洋红）**：胞质聚集导致核质转运受损并形成恶性循环的分支。
