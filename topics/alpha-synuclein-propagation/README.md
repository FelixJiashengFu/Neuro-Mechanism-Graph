## 分层标注

- **实线（青）**：构象模板化、细胞间转移的存在性（长期移植物中的宿主来源病理是最硬的人体线索）。
- **虚线（琥珀）**：隧道纳米管与受体介导摄取的在体权重、沿连接推进的普遍性。
- **点虚线（洋红）**：LAG3 一例的重复性问题、Braak 分期的反例。
