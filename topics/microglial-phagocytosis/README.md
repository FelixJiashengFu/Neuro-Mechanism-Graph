## 分层标注

- **实线（青）**：吞噬流程、补体介导的发育期突触消除、CD47 与 CD22 的刹车作用、TREM2 的遗传关联。
- **虚线（琥珀）**：TREM2 增强是否安全有效、DAM 状态的因果角色。
- **点虚线（洋红）**：误吞功能性突触、吞入后降解失败使细胞变成储存库。
