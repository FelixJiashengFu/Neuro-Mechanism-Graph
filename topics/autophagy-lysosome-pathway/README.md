## 分层标注

- **实线（青）**：六步流程、LC3 脂质化、SNARE 介导融合、mTORC1/AMPK/TFEB 调控、通量实验的方法学共识。
- **虚线（琥珀）**：只增强启动而不扩建溶酶体是否反而堵塞出口。
- **点虚线（洋红）**：融合或酸化失败使自噬体数量升高，从而让读数失去方向性。
